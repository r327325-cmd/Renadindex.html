  • استنتاج خصائص تنسيق الحدود[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span).
  • استنتاج مفهوم الهوامش وأنواعها (الداخلية والخارجية)[span_4](start_span)[span_4](end_span)[span_5](start_span)[span_5](end_span)[span_6](start_span)[span_6](end_span).
  • اكتساب المهارة في تطبيق تنسيق الحدود والخلفيات والهوامش عملياً[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span)[span_9](start_span)[span_9](end_span).
  • التعرف على خاصية ID و Class وكيفية استخدامها[span_10](start_span)[span_10](end_span)[span_11](start_span)[span_11](end_span)[span_12](start_span)[span_12](end_span).

🎨 خصائص الخلفية (background)
أهمية ومفهوم الخلفية: تحسين المظهر العام، جعل المحتوى أكثر وضوحاً وجاذبية، وإبراز العناصر المهمة[span_16](start_span)[span_16](end_span). تشمل خلفية الصفحة body وخلفية العناصر كالفقرات والعناوين[span_17](start_span)[span_17](end_span).
1. لون الخلفية (background-color): تُستخدم لتحديد لون خلفية العنصر[span_18](start_span)[span_18](end_span)[span_19](start_span)[span_19](end_span). طرق التحديد:
  • اسم اللون: red[span_20](start_span)[span_20](end_span)
  • الرمز السداسي عشري (Hex): مسبوق بـ # مثل #ff0000[span_21](start_span)[span_21](end_span)
  • نسب ألوان RGB: مثل rgb(100%, 40%, 20%)[span_22](start_span)[span_22](end_span)
  • قيم RGBA: تدعم الشفافية مثل rgba(255, 0, 0, 0.5)[span_23](start_span)[span_23](end_span).
2. صورة الخلفية (background-image): لإدراج صورة وفق الصيغة العامة:
background-image: url('image.jpg');
[span_24](start_span)[span_24](end_span)
3. تكرار صورة الخلفية (background-repeat):
  • repeat-x: تكرار أفقي فقط[span_25](start_span)[span_25](end_span).
  • repeat-y: تكرار عمودي فقط[span_26](start_span)[span_26](end_span).
  • repeat: تكرار أفقي وعمودي[span_27](start_span)[span_27](end_span).
  • no-repeat: عدم تكرار الصورة[span_28](start_span)[span_28](end_span).
4. موضع وتثبيت الصورة:
  • background-position: لا تعمل إلا إذا كان التكرار no-repeat[span_29](start_span)[span_29](end_span). تأخذ كلمات مفتاحية (مثل right top, center center, left bottom) أو إحداثيات نسب ومقاسات (مثل 2cm 2cm أو 50% 25%)[span_30](start_span)[span_30](end_span).
  • background-attachment: fixed (تبقى ثابتة عند التمرير) أو scroll (تتحرك مع النص)[span_31](start_span)[span_31](end_span).
الصيغة المختصرة (Shorthand):
background: [color] [image] [repeat] [attachment] [position];
[span_32](start_span)[span_32](end_span)
body { background: pink url('tvtc.jpg') no-repeat fixed right top; }
[span_33](start_span)[span_33](end_span)
📐 خصائص الحدود (Border)
وظيفة الخاصية: وضع حدود لأي عنصر والتحكم بلونه، وحجمه، ونمطه[span_34](start_span)[span_34](end_span).
عناصر الخصائص الأساسية:
  • border-style (نمط الحد): dotted (منقط)، dashed (متقطع)، solid (خط مستمر)، double (مزدوج)[span_35](start_span)[span_35](end_span).
  • border-color (لون الحد): تحديد اللون لجميع الجوانب بأسماء الألوان، الـ Hex، أو RGB[span_36](start_span)[span_36](end_span).
  • border-width (سمك الحد): بكلمات جاهزة (thin, medium, thick) أو بأرقام مع وحدات قياس مثل px, pt, cm, em[span_37](start_span)[span_37](end_span).
الصيغة المختصرة للحدود: الترتيب: (العرض - النمط - اللون)
h1 { border: 10px dotted blue; }
[span_38](start_span)[span_38](end_span)
📦 خصائص الهوامش (Margin & Padding)
أنواع الهوامش:
  • الهامش الخارجي (Margin): المسافة بين العنصر والعناصر المحيطة به في الصفحة[span_39](start_span)[span_39](end_span).
  • الهامش الداخلي (Padding): المسافة بين محتوى العنصر وحدوده[span_40](start_span)[span_40](end_span).
صيغ وقواعد كتابة القيم:
  • قيمة واحدة: تُطبق على جميع الجهات الأربع (مثال: padding: 30px;)[span_41](start_span)[span_41](end_span).
  • قيمتان: القيمة الأولى عمودياً (أعلى/أسفل) والثانية أفقياً (يسار/يمين) (مثال: padding: 20px 10px;)[span_42](start_span)[span_42](end_span).
  • أربع قيم: باتجاه عقارب الساعة: (أعلى - يمين - أسفل - يسار) (مثال: margin: 10px 20px 50px 30px;)[span_43](start_span)[span_43](end_span).
🏷️ تجميع العناصر (Class & ID)
المشكلة والهدف: تُستخدم لحل مشكلة تطبيق التنسيق على جميع عناوين أو فقرات الصفحة دفعة واحدة، وتسمح بتنسيق عناصر محددة دون غيرها[span_44](start_span)[span_44](end_span).

📂 العنصر الحاوي (<div>)

  • التنسيق الموحد باستخدام CSS لجميع العناصر الحاوية دفعة واحدة[span_58](start_span)[span_58](end_span).
  • إنشاء هياكل وتقسيمات الصفحة الرئيسية (Header, Content, Sidebar, Footer)[span_59](start_span)[span_59](end_span)[span_60](start_span)[span_60](end_span).
