🗺️ خريطة مفاهيم الوحدة الخامسة (خصائص CSS)

المرجع المختصر والشامل للمذاكرة السريعة

✨ إعداد الطالبة: ريناد اللحياني ✨
🎨 1. خصائص الخلفية (Background)
  • background-color: لتحديد لون الخلفية (بالاسم، السداسي #، أو RGB)[span_0](start_span)[span_0](end_span)[span_1](start_span)[span_1](end_span).
  • background-image: لإدراج صورة كخلفية عبر url('img.jpg')[span_2](start_span)[span_2](end_span).
  • background-repeat: تكرار الصورة (repeat-x, repeat-y, repeat, no-repeat)[span_3](start_span)[span_3](end_span).
  • background-position: مكان الصورة (تعمل مع no-repeat) مثل right top أو 50% 25%[span_4](start_span)[span_4](end_span)[span_5](start_span)[span_5](end_span).
  • background-attachment: تثبيت الخلفية بـ fixed أو تحريكها بـ scroll[span_6](start_span)[span_6](end_span).
📐 2. خصائص الحدود (Border)
  • border-style: نمط الحد (dotted منقط، dashed متقطع، solid مستمر، double مزدوج)[span_7](start_span)[span_7](end_span).
  • border-color: لتحديد لون الحدود للجهات الأربع[span_8](start_span)[span_8](end_span).
  • border-width: سمك الحد بكلمات (thin, medium, thick) أو قياس مثل 10px[span_9](start_span)[span_9](end_span).
  • الصيغة المختصرة: border: 10px dotted blue;[span_10](start_span)[span_10](end_span).
📦 3. الهوامش (Margin & Padding)
  • Padding (الهامش الداخلي): المسافة بين محتوى العنصر وحدوده[span_11](start_span)[span_11](end_span).
  • Margin (الهامش الخارجي): المسافة بين العنصر والعناصر المحيطة[span_12](start_span)[span_12](end_span).
  • قواعد القيم:
    • قيمة واحدة (لكل الجهات)[span_13](start_span)[span_13](end_span)
    • قيمتان (عمودي ثم أفقياً)[span_14](start_span)[span_14](end_span)
    • 4 قيم (أعلى، يمين، أسفل، يسار)[span_15](start_span)[span_15](end_span)
💻 4. التطبيق العملي للحدود والخلفيات
  • ربط صفحات الـ HTML بملفات الـ CSS عبر الوسم <link rel="stylesheet" ...>[span_16](start_span)[span_16](end_span).
  • تنسيق العناوين والفقرات والصور وتطبيق الخصائص المجتمعة للخلفيات والحدود والتهيئة العملية كما وردت بالمحاضرة[span_17](start_span)[span_17](end_span)[span_18](start_span)[span_18](end_span).
🏷️ 5. تجميع العناصر (Class & ID)
  • Class (الفئة): لتنسيق مجموعة عناصر متكررة، يُكتب قبلها نقطة .red[span_19](start_span)[span_19](end_span)[span_20](start_span)[span_20](end_span)[span_21](start_span)[span_21](end_span).
  • ID (المعّرف): لعنصر فريد لا يتكرر بالصفحة، يُكتب قبله #heading[span_22](start_span)[span_22](end_span)[span_23](start_span)[span_23](end_span)[span_24](start_span)[span_24](end_span).
  • يحلان مشكلة تأثير التنسيق على كل عناصر الصفحة دفعة واحدة[span_25](start_span)[span_25](end_span).
📂 6. وسم DIV وتقسيم الصفحة
  • حاوية عامة (<div>) لتجميع العناصر وتقسيم هيكل الصفحة[span_26](start_span)[span_26](end_span)[span_27](start_span)[span_27](end_span).
  • تُستخدم لتقسيم الموقع إلى أقسام رئيسية: رأس الصفحة (header)، المحتوى (content)، والتذييل (footer)[span_28](start_span)[span_28](end_span)[span_29](start_span)[span_29](end_span).
  • خصائص التحكم بالأبعاد: width و height[span_30](start_span)[span_30](end_span).
