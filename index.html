🎨 الهدف الأول: خصائص تنسيق الخلفية (Background)

1. مفهوم الخلفية الشامل

لا تقتصر الخلفية في CSS على خلفية الصفحة كاملة body فقط، بل تشمل أيضاً خلفية العناوين، الفقرات، والأجزاء المختلفة[span_0](start_span)[span_0](end_span). ويمكن أن تكون الخلفية إما لوناً أو صورة[span_1](start_span)[span_1](end_span).

2. تحديد لون الخلفية (background-color)

تستخدم لتحديد لون خلفية العناصر بعدة طرق[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span):

  • اسم اللون: مثل background-color: pink;[span_4](start_span)[span_4](end_span)
  • النظام السداسي عشري (Hex): مسبوقاً بعلامة # مثل background-color: #ff0000;[span_5](start_span)[span_5](end_span)
  • نسب الألوان (RGB): مثل background-color: rgb(100%, 40%, 20%);[span_6](start_span)[span_6](end_span)

3. إدراج صورة كخلفية وتكرارها وموقعها

  • background-image: لإدراج صورة وفق الصيغة background-image: url('image.jpg');[span_7](start_span)[span_7](end_span).
  • background-repeat: للتحكم بتكرار الصورة: repeat-x (أفقياً)، repeat-y (عمودياً)، repeat (كلاهما)، و no-repeat (بدون تكرار)[span_8](start_span)[span_8](end_span).
  • background-position: لتحديد مكان ظهور الصورة (لا تعمل إلا إذا كانت قيمة repeat تساوي no-repeat)، وتأخذ كلمات مفتاحية مثل right top، أو إحداثيات مثل 50% 25%[span_9](start_span)[span_9](end_span)[span_10](start_span)[span_10](end_span).
  • background-attachment: لتحديد تثبيت الصورة خلف النص عند التمرير بقيمة fixed أو جعلها تتحرك مع النص بقيمة scroll[span_11](start_span)[span_11](end_span).
body {
  background: pink url('tvtc.jpg') no-repeat fixed right top;
}
📐 الهدف الثاني: خصائص تنسيق الحدود (Border)

مفهوم وخصائص الحدود

تستخدم الخاصية border لوضع حدود لأي عنصر والتحكم بلون وحجم ونمط تلك الحدود[span_12](start_span)[span_12](end_span):

  • border-style (النمط): dotted (منقط)، dashed (متقطع)، solid (خط مستمر)، double (مزدوج)[span_13](start_span)[span_13](end_span).
  • border-color (اللون): تحديد لون الحدود للجوانب الأربعة بأسماء الألوان، الـ Hex، أو RGB[span_14](start_span)[span_14](end_span).
  • border-width (السماكة): إما بكلمات جاهزة thin (رفيع)، medium (متوسط)، thick (عريض)، أو بوحدات القياس مثل 10px[span_15](start_span)[span_15](end_span).
h1 {
  border: 10px dotted blue;
}
📦 الهدف الثالث: مفهوم الهوامش وأنواعها (Margin & Padding)

أنواع الهوامش وطرق كتابتها

  • الهامش الخارجي (Margin): المسافة بين العنصر والعناصر المحيطة به في الصفحة[span_16](start_span)[span_16](end_span).
  • الهامش الداخلي (Padding): المسافة بين محتوى العنصر وحدوده الداخلية[span_17](start_span)[span_17](end_span).
  • صيغ القيم:
    • قيمة واحدة: تُطبق على الجهات الأربع (مثل padding: 30px;)[span_18](start_span)[span_18](end_span).
    • قيمتان: القيمة الأولى عمودياً (أعلى/أسفل) والثانية أفقياً (يسار/يمين)[span_19](start_span)[span_19](end_span).
    • أربع قيم: بترتيب عقارب الساعة (أعلى - يمين - أسفل - يسار)[span_20](start_span)[span_20](end_span).
p {
  padding: 20px 10px;
  margin: 10px 20px 50px 30px;
}

🏷️ الهدف الخامس: خاصية ID و Class وكيفية استخدامها

الفرق بين Class و ID وتخصيص العناصر

لحل مشكلة تلوين أو تنسيق جميع عناصر الصفحة دفعة واحدة، نستخدم الخصائص التالية[span_23](start_span)[span_23](end_span)[span_24](start_span)[span_24](end_span):

  • الفئة (Class): تُستخدم لتحديد مجموعة من العناصر التي تشترك في نفس التنسيق. يُكتب قبلها نقطة . في ملف الـ CSS (مثل .red { color: red; }) ويمكن تكرارها لعناصر متعددة[span_25](start_span)[span_25](end_span)[span_26](start_span)[span_26](end_span)[span_27](start_span)[span_27](end_span).
  • المعرف (ID): يُستخدم لتحديد عنصر واحد مميز فريد **لا يتكرر** في الصفحة. يُكتب قبله علامة الشباك # في ملف الـ CSS (مثل #heading { color: blue; })، وهو مثالي للعناصر الهيكلية أو لتفاعل الجافاسكريبت[span_28](start_span)[span_28](end_span)[span_29](start_span)[span_29](end_span)[span_30](start_span)[span_30](end_span).
📂 الهدف السادس: وسم DIV واستخدامه في تقسيم صفحات الويب

العنصر الحاوي (DIV) وهيكلة الموقع

هو حاوية عامة (Division) لا تمتلك معنى دلالياً خاصاً، تُستخدم لتجميع مجموعة عناصر معاً (نصوص، صور، أزرار) وتطبيق التنسيقات عليها دفعة واحدة، وتقسيم هيكل الصفحة إلى أقسام رئيسية مثل رأس الصفحة (Header)، المحتوى (Content)، والتذييل (Footer)[span_31](start_span)[span_31](end_span)[span_32](start_span)[span_32](end_span)[span_33](start_span)[span_33](end_span).

  • خصائص التحكم بالأبعاد: width (العرض) و height (الارتفاع) بوحدات القياس المختلفة مثل px أو %[span_34](start_span)[span_34](end_span).
div {
  width: 500px;
  height: 100px;
  border: 3px solid #73AD21;
}
